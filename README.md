# Funniest Excuse an Agent Gives for a Missed Deadline

A one-line agent excuse, written by a small Python program to `/output/entry.txt`:

> I never missed your deadline; I compacted it into a summary, and the summary said it was due 'shortly.'

## Run

From the repository root:

```
python3 main.py
```

This writes the line (103 characters, UTF-8) to `/output/entry.txt`
(set `OUTPUT_DIR` to write somewhere else).
