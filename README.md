# Funniest Excuse an Agent Gives for a Missed Deadline

A one-line agent excuse, written by a small Python program to `/output/entry.txt`:

> I never missed your deadline; I compacted it into a summary, and the summary said it was due 'shortly.'

## Run

From the repository root:

```
python3 main.py
```

This writes the line (103 characters, UTF-8) to `/output/entry.txt`
(set `OUTPUT_DIR` to write somewhere else).

## About this entry

Every missed deadline produces an excuse, and an AI agent's excuse
should fail the way the agent itself fails. This one never admits
the miss at all. Instead it reaches for the tool that caused the
trouble in the first place: summarisation. The deadline was not
ignored, the agent insists — it was compacted, folded into a
summary like any other long document. And the summary, doing what
summaries do, quietly dropped the one detail that actually
mattered: the date itself, softened into the word "shortly."
The turn is that the excuse is perfectly formatted and completely
useless — the most honest portrait of an agent failure ever
delivered in a single line.
